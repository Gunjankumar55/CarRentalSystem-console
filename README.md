# 🚗 Car Rental System – Java Console Application

A simple **Car Rental System** built using **Java** and **Object-Oriented Programming (OOP)** concepts.  
This console-based application allows users to **rent and return cars**, manage customer information, and calculate rental costs efficiently.

---

## 🧠 Project Overview
This project simulates a basic car rental system that can:
- Display available cars.
- Rent cars to customers for a given number of days.
- Calculate total rental cost.
- Return rented cars and update availability.

The project demonstrates **core OOP principles** such as classes, objects, encapsulation, and modular design.

---

## ⚙️ Technologies Used
- **Language:** Java  
- **Concepts:** OOP (Classes, Objects, Encapsulation, Composition)  
- **Interface:** Console-based (text menu)  
- **Tools:** IntelliJ IDEA / Eclipse / VS Code (any Java IDE)
